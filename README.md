# 📸 Memories

Aplicação web **Full Stack** desenvolvida com React e Node.js para salvar e compartilhar memórias com imagens e comentários.

O usuário pode criar memórias, visualizar todas as memórias cadastradas e adicionar comentários em cada uma delas.

## 🚀 Tecnologias

### Frontend

* React
* JavaScript
* HTML5
* CSS3
* Axios

### Backend

* Node.js
* Express

### Banco de dados

* MongoDB
